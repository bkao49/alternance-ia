Comment ça marche

  1. 01

    Collecte

    Régulièrement, le bot lit les offres de sources autorisées, comme France Travail ou La Bonne Alternance, dans le respect de leurs conditions d'utilisation. Les doublons sont écartés.

  2. 02

    Score sur 5

    Chaque offre est comparée à ton profil : des règles simples, une proximité de sens, puis un avis argumenté. Tu vois pourquoi une offre obtient 4,4 et ce qui lui manque.

  3. 03

    CV adapté

    Pour les offres que tu retiens, un CV et une lettre sont préparés à partir de ton profil, uniquement avec des faits que tu as déclarés. Rien n'est ajouté.

  4. 04

    Validation humaine

    Tu relis, tu corriges, tu envoies toi-même. Une candidature ne passe « Envoyée » qu'après ta confirmation.

Le tableau de bord

Une page pour tout voir : les offres qui valent le coup, ce que fait le bot, et où en est chaque candidature.

Trois promesses, écrites dans le code

Aucun envoi automatique

Le bot prépare, il n'envoie jamais. Chaque candidature part de ta main, après relecture.

Aucune invention

Un CV ne contient que des faits présents dans ton profil. Une compétence que tu n'as pas déclarée n'y apparaît pas.

Données protégées

Données isolées par utilisateur, mots de passe hachés, rien n'est revendu. Le texte d'une annonce est lu comme une donnée, jamais comme une instruction.

Pour les recruteurs

Un projet personnel mené comme en équipe : une issue, une branche, une PR relue. Des agents IA écrivent une partie du code ; un humain relit et fusionne chaque changement.

Front
React 19, Vite, TypeScript, client généré depuis le contrat OpenAPI
Back
Python 3.12, FastAPI, un worker pour la collecte
Base
PostgreSQL et pgvector, isolation par utilisateur (Row Level Security)
IA
Claude, appelé via une passerelle unique : cache, plafond de coût et journal des appels
Sécurité
Argon2, session signée, protection CSRF, limitation des essais, aucun secret dans git
CI
GitHub Actions : lint, types, tests sur un vrai PostgreSQL, gitleaks, CodeQL, audit des dépendances
Déploiement
Docker Compose, dépendances et images épinglées
